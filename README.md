# Assignment Day

Mini game Flutter: trả lời nhanh các câu hỏi **logic**, **toán**, và **tiếng Anh** trong thời gian giới hạn.

## Chạy project

```bash
flutter pub get
flutter run -d chrome   # hoặc -d macos / thiết bị Android/iOS
```

## Cấu trúc

```
lib/
  main.dart
  models/question.dart
  data/questions.dart
  screens/
    home_screen.dart
    game_screen.dart
    result_screen.dart
```

## Yêu cầu

- Flutter SDK (stable)
- Để build Android: Android Studio / Android SDK
- Để build iOS: Xcode (macOS)
